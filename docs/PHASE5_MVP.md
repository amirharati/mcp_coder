## One-line goal

Move the context builder from *recency + `rg`* toward *relevance retrieval*, starting with delegation RAG (already indexed, not yet wired) and workspace-file summaries (new corpus) — with a proper RAG toolset (CLI + MCP) as the shared interface.

## North-star acceptance (dogfood)

Builder pulls a relevant fact from a **different spec's** prior delegation **and** a file the symbol scan would have missed — both visible in audit (`context_refs` / `delegation_pipeline` `rag_retrieval` phase) — and the same results are reachable via `mcp-coder search delegations` / `mcp-coder search files` CLI.

---

## Locked design decisions

| ID | Decision |
|----|----------|
| D-P5-1 | Phase 5 = infra + connect — not every corpus; advanced corpora (Corpus 3 distillation, Corpus 4 external) → Phase 5+/~8–9 |
| D-P5-2 | FTS + LLM file summaries first; embeddings only if P5-005 recall metric shows FTS insufficient |
| D-P5-3 | `retrieve(query, corpus, k) -> [ContextRef]` — one contract for all corpora; all future corpora plug in same shape |
| D-P5-4 | Separate DBs/lifecycles: `delegation_rag.db` (existing) vs `workspace_rag.db` (new); different update and retention patterns |
| D-P5-5 | Diffs live in `workspace_history` — RAG stores digests + path names, not patch bodies |
| D-P5-6 | Manifest sha256 change = lazy re-index signal for file summaries |
| D-P5-7 | Retrieval = explicit named pipeline phase (`rag_retrieval`) between `file_picker` and `context_assemble`; auditable in `delegation_pipeline` JSONL and CLI |
| D-P5-8 | RAG tools exposed as both MCP tools **and** CLI commands sharing the same implementation; CLI includes `--format plain` mode for direct prompt injection |

**Backend-neutral rule:** No Aider API terms (`fnames`, `yes=True`, `Coder`) in `core/rag/`, `core/context/`, or `core/specs/`. Retrieval contract is backend-agnostic.

### P5-002 — Delegation RAG → builder + delegation search CLI

**Goal:** Wire cross-spec delegation retrieval into the context builder as an auditable pipeline phase; add `mcp-coder search delegations` CLI.

**What:**
- Add `rag_retrieval` as a named phase in `delegation_pipeline` (between `file_picker` and `context_assemble`)
- Query `corpus="delegation"` using `task` + spec `## Goal` text; merge ranked hits with existing recency/same-spec history; deduplicate
- Inject top-k retrieved delegation snippets into builder prompt as `## Relevant prior work` block
- `context_refs[]` populated: `{kind: "delegation", delegation_id, spec_path, score, snippet}`
- **`mcp-coder search delegations <query>`** CLI: calls same backend as `rag_search` MCP; output table (id, spec, outcome, score, summary)
- `--format plain` flag: plain-text output for embedding directly in executor prompts — no JSON headers

**Files likely touched:** `server/mcp_server.py` (pipeline phase), `core/rag/retrieval.py`, `core/engine/context_builder_llm.py`, `core/logging/delegation_log.py`, `main.py` + CLI entry

**Acceptance criteria:**
- Delegation #N (spec B, task mentions `session.py`) retrieves Delegation #M (spec A, different spec_path, files `session.py`) — visible in `delegation_pipeline[rag_retrieval]` status + duration
- `mcp-coder search delegations "token refresh session"` returns ranked list with correct hits; output matches `rag_search` MCP equivalent
- `mcp-coder search delegations "token refresh" --format plain` produces clean text embeddable in a prompt without JSON parsing
- `builder_history_rag: false` (default) → `rag_retrieval` phase skipped; `true` → phase runs and populates `context_refs`
- JSONL `context_refs` shows delegation entries when toggle on

**Config toggle:** `builder_history_rag: false`

**Explicit out of scope:** Workspace-file corpus; executor-pull (BL-354)

**Can exit Phase 5 here (minimum viable).** Cross-spec memory in builder + proper search CLI is the core RAG value delivery.

**Worker spec:** `docs/tasks/P5-002-delegation-rag-builder-v1.md` (gitignored)

### P5-003 — Workspace-file corpus + workspace search toolset

**Goal:** Build `workspace_rag.db` with per-file LLM summaries and symbols; expose `workspace_search` as both MCP tool and CLI; lazy re-index on sha256 change.

**What:**
- `core/rag/workspace_indexer.py`: walk workspace, generate per-file summary (cheap LLM, `context_builder` role) + symbol list; store in `workspace_rag.db` (SQLite FTS5)
- Entry: `(path, sha256, llm_summary, symbol_list, indexed_at)`
- Staleness: manifest sha256 delta → re-index changed paths only (D-P5-6); no re-run needed if sha256 unchanged
- **`mcp-coder index-workspace`** CLI: full index or incremental `--changed-only`
- **`workspace_search` MCP tool**: keyword search over file summaries + symbols; `retrieve(corpus="workspace_files")` contract
- **`mcp-coder search files <query>`** CLI: same backend; `--format plain` for prompt injection
- Storage: `~/.mcp-coder/projects/<key>/workspace_rag.db`

**Files likely touched:** `core/rag/workspace_indexer.py` (new), `core/rag/retrieval.py` (new corpus), `server/mcp_server.py` (new tool), `main.py` + CLI, storage paths

**Acceptance criteria:**
- `mcp-coder index-workspace` on mcp-coder repo completes; `workspace_rag.db` populated
- `mcp-coder search files "delegation audit trail"` returns `core/logging/delegation_log.py` + related files in top-3
- File edited externally → sha256 changes → next `--changed-only` re-indexes that file only
- `workspace_search` MCP returns same ranking as `mcp-coder search files` for same query
- `--format plain` output embeddable in executor prompt without JSON parsing
- `workspace_file_rag: false` (default) → indexer does not run; `true` → lazily indexes on first delegate or explicit CLI call

**Config toggle:** `workspace_file_rag: false`

**Explicit out of scope:** Picker/builder wiring (P5-004); embeddings; cross-project federation

**Worker spec:** `docs/tasks/P5-003-workspace-file-corpus-v1.md` (gitignored)

### P5-004 — Picker/builder consume file corpus

**Goal:** Wire `retrieve(corpus="workspace_files")` hints into file picker and builder prompt; close the fuzzy file-recall gap (H2); audit file hits alongside delegation hits.

**What:**
- File picker: retrieve top-k file hints by task text; merge with symbol-scan candidates; spec `files_edit` contract invariant preserved (D-4 — no file summary grants edit rights)
- Builder prompt: inject top-k file summaries as `## Related files (by summary)` block — distinct from `## Relevant prior work` (delegation hits)
- `context_refs[]` includes workspace-file hits: `{kind: "workspace_file", path, sha256, score, snippet_from_summary}`
- `delegation_pipeline[rag_retrieval]` shows both corpus results (delegation + file)

**Files likely touched:** `core/context/file_picker.py`, `core/engine/context_builder_llm.py`, `server/mcp_server.py` (pipeline)

**Acceptance criteria:**
- Spec `## Goal: refactor auth module` with no explicit `files_read` declaration → picker with `workspace_file_hints: true` surfaces `core/host/cursor.py` (summary: "handles Cursor host transcript and session") that `rg` symbol scan would not find by task keywords alone
- `context_refs` in JSONL shows workspace-file hits alongside delegation hits
- `workspace_file_hints: false` toggle (default; layered on `workspace_file_rag`) → file hints not injected
- Spec `files_edit` contract: file hints appear only as read candidates, never auto-added to edit tier — D-4 invariant holds
- Existing spec-contract and gateway tests pass

**Config toggle:** `workspace_file_hints: false`

**Recommended Phase 5 exit.** P5-004 running in dogfood with at least one delegation showing both corpus hits in `context_refs`.

**Worker spec:** `docs/tasks/P5-004-file-corpus-picker-builder-v1.md` (gitignored)

### P5-005 — Measure + lean-ref seam *(optional capstone — does not gate phase exit)*

**Goal:** Validate FTS recall (H3: is FTS sufficient?); document token cost before/after Phase 5 toggles; add `context_refs[]` as lean refs in JSONL; make embeddings go/no-go decision.

- `context_refs[]` lean refs: ensure JSONL stores `{kind, corpus, id, sha256, score}` without duplicating full bodies (pre-shapes BL-356)
- Record embeddings go/no-go verdict in `rag-gap-analysis.md` § Open evidence

**Acceptance criteria:**
- FTS recall metric computed and recorded (pass/fail threshold: set after results)
- Token cost delta documented in § Results below
- `context_refs[]` in JSONL contains no duplicated body text — only refs + scores
- Embeddings decision recorded

**Can be started during or after P5-004 dogfood; does NOT gate phase exit.**
