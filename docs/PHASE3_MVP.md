## Phase 3 thesis

> **mcp-coder owns workspace truth and planner-visible history** at delegation granularity — independent of user git — then layers **cross-session memory (RAG)** and **gates** on top. Phase 2 shipped the context compiler; Phase 3 makes the audit loop **complete and trustworthy** in messy sandboxes, and gives Cursor a durable trail of what failed and what changed between MCP calls.

## Architecture (summary)

Phase 3 extends the Phase 2 audit loop — especially **layer 4 (result)** and **planner-facing artifacts** — without replacing JSONL (`~/.mcp-coder/.../delegations.jsonl` remains canonical).

```text
Before delegate:  workspace manifest snapshot  →  workspace_history.db
After delegate:   manifest delta  →  files_changed (non-git)  →  optional gateway/revert
Parallel:         attempt archive (failures)  →  specs/attempts/
Later:            RAG index from delegation summaries + diffs
```

**Storage (locked):** `~/.mcp-coder/projects/<project_key>/workspace_history.db` — not manifests under workspace `.mcp-coder/` (avoids recursion). See [WORKSPACE_HISTORY.md](./OTEHR_RELATED_IDEAS/WORKSPACE_HISTORY.md).
