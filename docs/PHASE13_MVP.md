## One-line goal

Make Phase 12 trustworthy in production: dogfood end-to-end, read the logs, fix what breaks, document what we actually built.

## North-star acceptance

After Phase 13:

1. **Dogfood complete** — at least one multi-delegation scenario run via CLI and one via Cursor MCP; trace/log checklist signed off in P13-001 § Results.
2. **Sequence validated** — pause/resume, project state load/save, singleton warm path, reviewer→state, planner pre-injection, and `supervisor_session_reset` (when applicable) observed in traces with expected ordering.
3. **Docs match reality** — `supervisor-orchestration-layer.md` and phase exit tables reflect shipped Phase 12; stale Phase 12 planning cruft archived or marked historical.
4. **Regression safety** — integration tests added for gaps found in dogfood (P13-003).
5. **Backlog trimmed** — end-of-phase backlog review: 2–4 low-hanging items closed or explicitly deferred; no unbounded scope creep.

## Strategic context

Phase 12 shipped the orchestration **control plane** (state, memory, tool runner, pause/resume, executor reset hint). Unit tests pass (87). Live dogfood and doc consolidation were intentionally deferred here so we don't close a phase on theory alone.

**Phase 13 is NOT:**

- BL-543 checkpoints B/C (full continuation brief, confirm_ask enrichment)
- BL-546 smart executor context adaptation
- BL-526 Architect/CTO role

Those stay in backlog until Phase 13 exit review prioritizes them for a later phase.

## Milestones

### P13-001 — Dogfood capstone + trace analysis

**Status:** `pending`
**Goal:** Run real delegations exercising Phase 12 paths; capture delegation IDs; analyze traces and server logs; file `P13-ISS-*` for bugs; produce a signed checklist.

**Scenarios (minimum):**
1. **Multi-delegation same project** — 2–3 `delegate_to_agent` calls with same `spec_path` prefix; verify `project_state.json` grows; planner `planner_context_sources` includes `project_state` on later runs.
2. **Pause/resume** — delegation that escalates to `needs_input`; resume with `answer=`; verify pipeline stages skipped; `supervisor_resumed` in trace.
3. **Optional:** `start_fresh=True` abandons paused state; singleton identity across delegations (`project_state_loaded` once per process after warm start).

**CLI path:** `mcp-coder delegate` (full run) on a toy spec in a test workspace.
**Cursor path:** `delegate_to_agent` MCP tool on same or parallel scenario.

**Analysis tools:** `mcp-coder trace inspect`, `mcp-coder logs tail`, `project_state.json` on disk.

**Deliverable:** Spec § Results with delegation IDs, checklist table, bugs filed, recommended P13-003/P13-004 items.
